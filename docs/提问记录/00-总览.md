## 知识掌握地图

**最后更新：2026-10-28**

### 一、认证与安全

| 知识点 | 状态 |
|---|---|
| 两套认证机制的区别（JWT vs 会话 token） | ✅ 第一轮 |
| BCrypt vs MD5（随机盐、彩虹表、故意慢） | ✅ 第三轮 |
| `verified` 双阶段校验（status + verified 才能交易） | ✅ 第三轮 |
| 卡状态机（1 正常 / 2 锁定 / 3 挂失 / 4 注销） | ✅ 第三轮 |
| 会话超时的两个动作（刷新 last_active vs 标记超时） | ⚠️ 第三轮，时机没说清 |
| ATM 为什么不能用 JWT（无状态 = 不可撤回） | ⚠️ 第三轮，没抓住核心 |
| 退卡是"改状态"不是"删记录" | ❌ 第三轮 |
| 全局异常处理器只拦"抛出去的异常" | ❌ 第二轮 |

### 二、事务与并发

| 知识点 | 状态 |
|---|---|
| 事务回滚的触发方式（抛异常 → 回滚） | ✅ 第一轮 |
| 条件更新 / CAS（防超扣、防超卖） | ✅ 第二轮 |
| 原子自增（防丢失更新，`x = x + 1`） | ✅ 第三轮 |
| 按 `account_id` 升序更新防死锁 | ✅ 第二轮 |
| `@Transactional` 防"多表不一致"，不防"余额不足" | ⚠️ 需能复述 |
| `verifyPassword` 加事务 → 永远锁不了卡 | ⚠️ 第三轮，方向说反了 |
| 单表操作不需要 `@Transactional` | ✅ 第二轮 |

### 三、数据访问
